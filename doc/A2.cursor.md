Cursor
======

Cursor is an AI-native code editor designed to accelerate software engineering 
by deeply embedding artificial intelligence into the core programming workspace

Learning how to use Cursor is a moving target, but likely not in a way that should 
discourage you.

Because Cursor is at the absolute forefront of AI-assisted engineering, the platform,
its UI, and the underlying "best practices" evolve on a monthly—sometimes weekly—basis.
What worked perfectly six months ago might be an outdated workflow today.

Install Cursor on Ubuntu
========================

```
# add Cursor's GPG key
curl -fsSL https://downloads.cursor.com/keys/anysphere.asc | gpg --dearmor | sudo tee /etc/apt/keyrings/cursor.gpg > /dev/null

# add the official Cursor repository
echo "deb [arch=amd64,arm64 signed-by=/etc/apt/keyrings/cursor.gpg] https://downloads.cursor.com/aptrepo stable main" | sudo tee /etc/apt/sources.list.d/cursor.list > /dev/null

# run apt update & install
sudo apt update
sudo apt install cursor
```

Getting started using Cursor
============================

Create test directory, and test/test.c file containing this program code which 
contains errors. Cursor will be asked to fix the errors.
```
int main()
{
    printf("hello\n");
    return "goodbye";
}
```

Run cursor:
```
cd test
cursor .
```

File > New Agent

In the input area you should see:
- '+': this allows you to select what you will be doing, such as:
  - 'Ask': ask question, Cursor will not make any edits in Ask mode
  - 'Plan': generate an implementation plan
- Model: such as 'Grok 4.7 High'.

Select 'Plan', and enter, 'The code fails to compile, please fix.'

Cursor will identify the errors in the code.
To have Cursor apply fixes to the code select 'Build'.

In the pane on the right side, select '+' to open a new tab, and select 'Terminal'.
You can view the corrected test.c from this bash terminal.

Back in the center pane you should now see 'Send follow-up'.
You can request Cursor to make more changes. 
For example 'Add Makefile'. Back in the bash terminal you can now run 'make'.

Misc Notes
==========

Some key bindings:
- Ctrl -           decrease font size
- Ctrl +           increase font size
- Ctrl ,           settings
- Ctrl k           AI prompt bar  
- Ctrl Shift P     command palette
- Ctrl Shift /     keyboard shortcuts (Currently no longer working)

User settings:
- /update-cursor-settings
- settings file is here: ~/.config/Cursor/User/settings.json
